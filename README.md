# 業務PCで生成AIを使うときの信号ルール

**結論：作るのは私用PC／スマホ。業務PCは、完成品を受け取るだけ。**
**入れる情報は「信号」で分ける。それだけ守れば、だいたい大丈夫です。**

> 詳しく知りたい人向け → [詳細版](%E8%A9%B3%E7%B4%B0%E7%89%88.md)（脅威の考え方、FAQ、万が一の手順まで）
> ※ 各社のセキュリティ規程・顧客との契約が優先です。規程で禁止されている業務では使いません。

## 3つの原則

1. **入れなかった情報は、漏れない** ― 監視ログにもAI側の保存にも載らない、一番強い守り方
2. **会社の監視は、逃げるものではなく前提にする** ― 記録されても困らない使い方に寄せる
3. **迷ったら、厳しい方へ** ― 🟡か🔴か迷ったら🔴

## 信号ルール（これが本体）

| 信号 | 入れる情報 | 扱い方 |
|---|---|---|
| 🔴 入れない | 顧客名・IP・認証情報（ID／パスワード／APIキー）、外部開示禁止の情報、個人情報（氏名と結びつく情報・健康情報）、未公開の経営数値 | AI自体に入れない。相談したい場合は、固有名詞を外して一般論として聞く |
| 🟡 加工すればOK | 社内文書・コードの抜粋 | 固有名詞を `[CLIENT_A]` `[IP_A]` のように置換し、人物は対応表を別管理するコード（`S01` 等）にしてから。貼る前に目視確認 |
| 🟢 そのままOK | 一般的な技術の質問、公開情報の調査、テンプレート作り | そのまま入力してよい |

## スクリーンショットを貼るとき

画像の中の文字もAIは読みます。「画像だから安全」ではありません。

1. 必要な部分だけに**切り取る**
2. 機密部分はモザイクではなく**ベタ塗り**で消す
3. 貼る前に**拡大して端まで見る**（URLバー、タブ、タイトル、一覧の他の行、通知が写り込みやすい）
4. 加工前の元画像は渡さない。手順書用は、できれば検証環境・サンプルデータの画面で撮る

## 一番安全な型

- 作成・議論・入力：**私用PC／スマホ**で完結
- 業務PC：完成品の**ダウンロード（または表示）だけ**
- ただし機密を含む完成品は、業務PCにダウンロードせず表示のみ
- 私用端末でも🔴は入れない（AI側への保存という問題は端末を変えても残るため）

## 入力前チェック（10秒）

- [ ] 🔴が混ざっていないか
- [ ] 固有名詞・IP・認証情報を置換したか（人物はコード表記か）
- [ ] スクショは切り取り＋ベタ塗り＋拡大確認をしたか
- [ ] そもそも規程・契約で禁止されていないか

## もし間違えて入れてしまったら

1. 認証情報を入れた場合は、履歴削除より先に**その認証情報を無効化・再発行**
2. そのチャット履歴を削除
3. 隠さず、会社の情報セキュリティ担当・上長へ報告
